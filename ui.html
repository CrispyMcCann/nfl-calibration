NFL game-script calibration

Prediction Log

Your number goes in before the odds, and before kickoff. Rows stay editable until the game starts, then lock for good — every amendment is kept on the record.

How to use this — read once, refer if you forget
  1. Generate the week's slate: in the repo, python slate.py --week N --json > week_N.json.
  2. In Step 1 below, pick the week_N.json file, hit Load slate. The queue starts automatically. Manual entry is a fallback only.
  3. For each prop, in order: fill line, the over/under is locked to the side the queue assigned (over on core, under on control), so enter your probability that that side hits as a decimal (0.61 not 61), write why in one sentence naming the mechanism. Only then do the odds fields wake up.
  4. Enter FanDuel's American odds for both sides. Include the sign: -115, +105. The devigged market probability appears live under the fields.
  5. Hit Log & next. The queue advances automatically. Do the whole queue in one sitting so the information set stays constant.
  6. If a prop should be skipped (player out, no line, book suspended), write the reason into the why field and hit Skip this one. The skip is recorded in the CSV with the reason attached.
  7. When the queue is empty, hit Copy all as CSV, paste into ui_export.csv in the repo (replace its contents), run python merge.py, then git add predictions.csv && git commit -m "week N logged" && git push. Never paste straight into predictions.csv: it holds resolved outcomes this page doesn't have. The commit before kickoff is what makes the record evidence.
  8. Shortly before each game's kickoff, use the row's Close price button to capture the closing FanDuel price. After each game-day batch of closes: Copy all as CSV into ui_export.csv, python merge.py, commit + push.
  9. Tuesday morning: python resolve.py to fill outcomes from nflverse, then python score.py --plot calibration_wN.png to update the calibration curve. Commit both.
