NFL game-script calibration

Prediction Log

Your number goes in before the odds, and before kickoff. Rows stay editable until the game starts, then lock for good — every amendment is kept on the record.

How to use this — read once, refer if you forget
  1. Generate the week's slate: in the repo, python slate.py --week N --json > week_N.json. Open the file, copy the whole thing.
  2. Open Load a week's slate below, paste the JSON, hit Load slate, then Work the queue. This is the primary path — the manual form is a fallback.
  3. For each prop, in order: fill line, pick over/under (the queue pre-selects the expected side), enter your probability as a decimal (0.61 not 61), write why in one sentence naming the mechanism. Only then do the odds fields wake up.
  4. Enter DraftKings' American odds for both sides. Include the sign: -115, +105. The devigged market probability appears live under the fields.
  5. Hit Log & next. The queue advances automatically. Do the whole queue in one sitting so the information set stays constant.
  6. If a prop should be skipped (player out, no line, book suspended), write the reason into the why field and hit Skip this one. The skip is recorded in the CSV with the reason attached.
  7. When the queue is empty, hit Copy all as CSV, paste into predictions.csv, then git add predictions.csv && git commit -m "week N logged" && git push. The commit before kickoff is what makes the record evidence.
  8. Shortly before each game's kickoff, use the row's Close price button to capture the closing DraftKings price. Commit again after each game-day batch of closes.
  9. Tuesday morning: python resolve.py to fill outcomes from nflverse, then python score.py --plot calibration_wN.png to update the calibration curve. Commit both.
